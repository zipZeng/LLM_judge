## 二、跑起来（最短路径）

```bash
git fetch origin
git checkout feature/caobin        # 必须切分支，main 上没有这个模块
cd synthesis
pip install requests python-dotenv # 依赖只有这两个
cp .env.example .env               # 填 Key，见下
```

```bash
# 1) 不花钱先看一眼：只打印将要发起的调用，不联网
python generate.py --dry-run

# 2) 免 Key 演示（答辩现场用这个；实测约 0.4 秒，不调 API、不写文件、不需要 .env）
python compare_models.py --from-report data/compare/20260911_104142

# 3) 真跑（要 Key、花 token；单次 4–7.5 分钟）
python generate.py && python compare_models.py && python export.py

# 4) 回归测试（四个脚本，不联网、不花 token、不需要 Key，共 92 项）
python test_jsonx.py    # 11 项
python test_llm.py      # 18 项
python test_export.py   # 33 项
python test_compare.py  # 30 项
```

**Key**：两个，写在 `synthesis/.env`（照 `.env.example` 填）

- `DEEPSEEK_API_KEY` —— DeepSeek 开放平台
- `SILICONFLOW_API_KEY` —— 硅基流动，GLM-5.3 / Qwen3.6 共用

**缺哪个 Key 就自动跳过哪家模型**，不会整个跑不起来。读取优先级：
`synthesis/.env` → `git_hub/LLM_judge/.env` → 系统环境变量。
模型 tag 或接口地址要改，只改 `synthesis/llm.py` 的 `PROVIDERS` 一处。

## 五、接手必读的坑

1. **`.env` 里有真实 Key** —— 永不入库、永不提交、永不外发。GitHub 上一旦泄漏，立刻去平台吊销。

2. **`synthesis/.gitignore` 的「反选」写法不能乱动**：必须先把 `data/` 改成 `data/*`、再用
   `!data/export/` 放行（gitignore 规则：**父目录被排除时 `!` 反选不回来**）。compare 那几行是
   **四行一组**的写法，少了后两行会把以后新跑的对比报告**全部静默提交**。改完用
   `git check-ignore -q` 的**退出码**验证（不是看输出）。
   ⚠ 仓库根 `.gitignore` 是队友 zzp 的，**不要改**。

3. **开发副本 ≠ 仓库副本，而且现在两者内容不一样，别直接拷**：
   - 开发副本 `大四上_实训项目/synthesis/` 目前**整份停在 `wip/diversity`（撤回的那一轮）**状态
   - 与仓库副本的差异：多出 `diversity.py` / `test_diversity.py`；`llm.py`、`test_llm.py`、
     `README.md`、`.gitignore` 四个文件都是那一轮的版本（例如 `test_llm.py` 开发副本 37 项 vs 仓库副本 18 项）
   - **交接与提交一律以仓库副本 `git_hub/LLM_judge/synthesis/` 为准**，且改完必须在仓库副本重跑测试

4. **测试是自跑脚本，不是 pytest** —— 直接 `python test_xxx.py`。用 `python -m pytest` 会在
   `test_compare.py` 的 `sys.exit()` 上抛 `INTERNALERROR`，看起来像测试全挂了，其实没有。

5. **提交信息不加任何 AI 署名** —— 不要 `Co-Authored-By`，PR 描述也不要 `Generated with Claude Code`。
   历史上发过一次，已 amend 掉重推，别再犯。

6. **本机环境**：Git Bash 下 `cd /d` 是 cmd 语法、会报 `too many arguments`；`git diff` 会进 less
   分页器（脚本里加 `git --no-pager`）；**没有 `gh` CLI**，且**打不开 github.com** —— PR 页面自己开浏览器看。
