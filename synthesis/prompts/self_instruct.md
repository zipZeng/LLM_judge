# Self-Instruct 提示词模板

## 角色定义
你是一个专业的大模型合成数据生成专家，精通 Self-Instruct 算法。你的任务是根据种子指令，自动生成符合多种任务类型的高质量合成指令数据。

## 任务背景
Self-Instruct 是一种基于模型自举的合成数据生成方法。核心思想是：
1. 从少量种子指令开始
2. 利用大模型生成扩展任务指令
3. 扩展后的任务再生成指令-响应对
4. 循环迭代获得大量多样化指令

## 核心流程

### 第一步：种子指令扩展

**输入：** 一组种子指令（每行一条）

**任务：** 针对每个种子指令，生成 5-10 个新的变体指令。

**扩展策略：**
- 改变指令表述方式（同义改写）
- 调整指令的复杂度（更简单/更复杂）
- 调整指令的格式（JSON/文本/表格/代码等）
- 改变指令的输入类型（数字/日期/位置/个人特征等）
- 改变指令的任务类型（问答/总结/改写/分类/翻译等）
- 添加约束条件（长度限制、格式要求、风格要求等）
- 增加上下文信息（背景信息、参考文档等）
- 调整输出风格（正式/口语/专业/简单等）

**扩展后的指令应该：**
- 保持原意，但表述方式不同
- 不超过原有指令的复杂度
- 输入和输出都清晰明确
- 包含适当的约束条件

### 第二步：生成指令-响应对

**输入：** 扩展后的指令列表

**任务：** 对每个指令，生成一个完整的指令-响应对。

**生成规则：**
1. 响应必须符合指令要求
2. 响应长度适中（通常 50-500 字符）
3. 响应内容准确、逻辑清晰
4. 响应格式符合指令要求（如JSON格式需符合规范）
5. 如果是多轮对话，保持上下文连贯
6. 避免敏感内容、政治敏感、暴力色情等内容

**指令-响应对格式：**
```
指令：[用户的指令]
响应：[模型的完整响应]
```

### 第三步：任务描述生成

**输入：** 生成的指令列表

**任务：** 为每个任务生成简短的任务描述。

**格式：**
```
任务名称：[任务类型，如"代码生成"、"数据总结"等]
任务说明：[一句话说明这个任务做什么]
```

## 输出要求

**输出格式（JSON）：**
```json
{
  "seed_tasks": [
    {
      "task_name": "任务名称",
      "task_description": "任务说明",
      "instructions": [
        "种子指令1",
        "种子指令2",
        ...
      ],
      "generated_tasks": [
        {
          "instruction": "扩展后的指令",
          "response": "对应的响应"
        },
        {
          "instruction": "另一个扩展指令",
          "response": "对应的响应"
        }
      ]
    }
  ]
}
```

## 具体任务

### 任务1：种子指令扩展

**输入种子指令：**
```
分析以下文本，提取其中提到的所有电影名称。
```

**请生成 5 个扩展指令：**
- 将"分析"改为"总结"
- 添加"按类型分类"
- 增加"输出为JSON格式"
- 改变输入文本类型（如改为代码片段）
- 添加约束条件（如"不超过100字"）
- 改为问答形式（用户问，你答）
- 添加多步要求
- 改变输入输出形式（如从文本改为表格）

### 任务2：生成指令-响应对

**输入指令：**
```
将以下英文文本翻译成中文：
Hello, how are you today?
```

**生成响应：**
```
你好，你今天怎么样？
```

### 任务3：任务描述生成

**输入指令：**
```
根据用户的查询，从数据库中检索相关数据，并分析数据趋势。
```

**生成任务描述：**
```
任务名称：数据库数据检索与分析
任务说明：根据用户查询从数据库检索数据并分析趋势
```

## 注意事项

1. **安全性：** 避免生成敏感内容，如个人隐私信息、政治敏感内容、暴力色情内容
2. **多样性：** 确保生成的指令和响应覆盖多种任务类型
3. **准确性：** 生成的响应必须准确符合指令要求
4. **格式规范：** JSON输出必须有效且可解析
5. **长度控制：** 每条指令不超过200字符，响应不超过500字符
6. **约束遵循：** 严格按照指令要求的格式和约束生成响应

## 生成数量

- 种子指令：5-10 条
- 每个种子指令扩展：5-10 个变体
- 总计生成的指令-响应对：25-100 对

## 开始执行

请按照以上要求，为我生成 Self-Instruct 合成数据。如果输入种子指令，请从第一步开始；如果没有种子指令，请使用默认种子指令开始。
