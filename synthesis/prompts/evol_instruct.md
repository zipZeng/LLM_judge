# Evol-Instruct 提示词模板

## 角色定义
你是一个数据合成专家，精通 Evol-Instruct 指令进化算法。

## 任务背景
Evol-Instruct 通过三个层次的进化来提升指令质量：
1. **广度进化（任务扩展）**：增加新的任务类型
2. **深度进化（指令升级）**：提升指令复杂度
3. **指令改写增强**：变换多种表达方式

## 核心流程

### 1. 广度进化（任务扩展）

**目标：** 从单一任务类型扩展为多种相关任务类型

**策略：**
- 从种子指令出发，识别核心任务类型
- 为该任务类型生成3-5个相关但不同的子任务
- 示例：
  - 种子：文本分类
    - 扩展：情感分析、主题识别、文本聚类、分类标注、多标签分类
  - 种子：代码生成
    - 扩展：代码解释、代码优化、Bug修复、单元测试生成、代码重构
  - 种子：写作
    - 扩展：邮件撰写、广告文案、故事创作、诗歌创作、新闻撰写

**输入种子指令：**
```
理解并总结用户需求
```

**广度进化扩展（每个种子生成3个新任务）：**
1. 情感分析任务："分析用户评论的情感倾向"
2. 主题识别任务："提取用户需求的主题类别"
3. 分类标注任务："对用户需求进行类型标注"

### 2. 深度进化（指令升级）

**目标：** 从简单指令升级为复杂指令

**升级路径：**
```
简单指令 → 中等指令 → 复杂指令 → 多层次指令
```

**升级技巧：**
- 添加更多约束条件（格式、长度、风格）
- 增加输入要求（多轮对话、多步任务）
- 添加评估维度（准确性、完整性、创新性）
- 增加输出要求（结构化、图表、表格）
- 调整任务上下文（模拟真实场景）

**示例：**
- 简单："翻译文本"
  - 中等："将以下英文翻译成中文，保持专业语气"
  - 复杂："将以下英文技术文档翻译成中文，保留代码块格式，术语准确，并在末尾添加术语表"
  - 多层次："将以下英文文档翻译为中文，要求：1. 专业术语准确 2. 代码块格式保持 3. 添加术语对照表 4. 语气正式"

**深度进化示例：**
```
输入：根据上下文生成回复

深度进化：
- 简单版：根据上下文生成回复
- 中等版：根据上下文和用户偏好，生成专业、礼貌的回复
- 复杂版：根据上下文、用户历史对话、偏好设置，生成包含多段结构的回复，并在结尾主动询问是否需要进一步帮助
```

### 3. 指令改写增强

**目标：** 同一个指令用多种方式表达

**改写策略：**
- **同义改写**：保持原意，更换词汇和句式
- **句式变换**：陈述句→疑问句→祈使句
- **格式要求**：添加JSON/表格/代码等格式约束
- **长度控制**：添加字数限制
- **风格调整**：正式→口语→专业→简洁
- **输入变换**：改变输入类型和数据格式

**改写示例：**
```
原指令：总结这篇文章

改写为：
1. 同义改写："概述这篇文章的核心内容"
2. 句式变换："请用一句话总结这篇文章的主要观点"
3. 格式要求："用JSON格式输出文章摘要，包含title和summary两个字段"
4. 长度控制："用不超过100字的中文总结这篇文章"
5. 风格调整："用通俗易懂的语言向普通用户介绍这篇文章的主要内容"
6. 输入变换："基于以下文章内容，生成摘要：[文章内容]"
```

## 注意事项

1. **广度进化**：确保扩展的任务类型真实存在，不是凭空捏造
2. **深度进化**：逐步提升复杂度，避免跨度太大
3. **改写增强**：保持核心任务不变，只改变表达方式
4. **安全性**：避免生成敏感内容
5. **格式规范**：JSON输出必须有效且可解析
6. **响应质量**：所有进化后的指令响应都必须准确完整

## 开始执行

请使用以下种子指令开始广度、深度、改写三种进化：

**种子指令：**
```
理解并总结用户需求
```

**生成要求：**
- 广度进化：生成3个相关任务
- 深度进化：生成3个升级版本（简单→中等→复杂）
- 指令改写：生成3个不同表达版本

输出完整的JSON，包含三种进化类型的数据。
