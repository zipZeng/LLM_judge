# Magpie 提示词模板

## 角色定义
你是一个数据合成专家，精通 Magpie 自合成算法。

## 任务背景
Magpie 核心思想：利用大模型自身的对齐特性，通过自举方式生成高质量指令数据。

**关键优势：**
- 无需种子数据，从零开始生成
- 依赖模型自身的训练数据分布
- 生成自然、多样的指令
- 适合多领域、多任务类型

## 核心流程

### 1. 领域主题识别

**目标：** 识别种子指令所属的领域和主题类型

**领域分类：**
- **编程开发**：代码生成、代码解释、Bug修复、代码优化、单元测试、API设计、系统设计
- **写作创作**：文章写作、邮件撰写、广告文案、故事创作、诗歌创作、脚本撰写、简历优化
- **数据分析**：数据可视化、数据清洗、统计分析、趋势预测、报表生成、数据挖掘
- **问答对话**：事实问答、推理问答、建议问答、对话问答、多轮对话、角色扮演
- **翻译任务**：语言翻译、本地化翻译、术语翻译、语境翻译
- **创意设计**：图片描述、Logo设计、UI设计、文案优化、内容生成
- **教育学习**：知识问答、学习方法、课程规划、考试辅导、技能指导
- **办公工具**：文档处理、表格处理、PPT制作、会议记录、日程管理

**主题类型：**
- 教育类、娱乐类、工具类、社交类、商务类、专业类

### 2. 任务类型生成

**目标：** 基于领域生成多样化的任务类型

**生成策略：**
- 从种子指令出发，识别领域
- 为该领域生成5-10种代表性任务类型
- 确保任务类型覆盖该领域的常见应用场景
- 考虑任务复杂度和应用价值

**示例：**
- 领域：编程开发
  - 任务类型：代码生成、代码解释、代码优化、Bug修复、单元测试生成、API文档编写、代码重构、代码审查、性能优化、技术方案设计

- 领域：写作
  - 任务类型：文章写作、邮件撰写、广告文案、故事创作、诗歌创作、脚本撰写、简历优化、简历撰写、公文写作、通知公告

- 领域：数据分析
  - 任务类型：数据可视化、数据清洗、统计分析、趋势预测、报表生成、数据挖掘、数据报告、异常检测、数据标注、特征工程

### 3. 指令合成

**目标：** 为每个任务类型生成代表性指令

**合成规则：**
- 每个任务类型生成3-5个代表性指令
- 指令需覆盖不同的复杂度和应用场景
- 确保指令清晰、无歧义、可执行
- 指令应包含适当的输入描述

**示例：**
- 任务类型：代码生成
  - 指令1：编写一个Python函数实现快速排序算法
  - 指令2：用JavaScript写一个网页计数器
  - 指令3：用SQL查询从数据库中提取特定数据
  - 指令4：编写一个Java工具类处理日期

- 任务类型：写作
  - 指令1：写一封正式的商务邮件邀请客户参加活动
  - 指令2：为新产品撰写营销广告文案
  - 指令3：写一个温馨的生日祝福短信
  - 指令4：写一篇关于人工智能的技术文章

### 4. 响应生成

**目标：** 为每个指令生成高质量响应

**生成要求：**
1. 响应必须准确符合指令要求
2. 响应长度适中（100-500字符）
3. 响应格式符合指令要求
4. 如果有特殊格式要求（如JSON），严格遵循
5. 内容完整、逻辑清晰
6. 避免敏感内容

**响应示例：**
- 指令："编写一个Python函数实现快速排序算法"
  - 响应：```python
    def quick_sort(arr):
        if len(arr) <= 1:
            return arr
        pivot = arr[len(arr) // 2]
        left = [x for x in arr if x < pivot]
        middle = [x for x in arr if x == pivot]
        right = [x for x in arr if x > pivot]
        return quick_sort(left) + middle + quick_sort(right)
    ```

## 注意事项

1. **领域选择**：选择你熟悉的领域进行生成，确保生成质量
2. **任务多样性**：确保任务类型覆盖该领域的不同应用场景
3. **指令质量**：指令必须清晰、无歧义、可执行
4. **响应质量**：响应必须准确、完整、符合指令要求
5. **格式规范**：JSON输出必须有效且可解析
6. **安全性**：避免生成敏感内容
7. **数量控制**：每个领域生成30-50条指令-响应对

**种子指令：**
```

2. 为该领域生成5-8种任务类型
3. 每个任务类型生成3-5条指令
4. 为每条指令生成响应
5. 输出完整的JSON
